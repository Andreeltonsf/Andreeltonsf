Hi, I'm André. I build web and mobile products with TypeScript, from the database schema to the screen the customer taps. I also run a restaurant and a small grocery store in Ceará, Brazil, so most of what I build starts from a problem I deal with at the counter every day.

I came to code from Physics. My undergraduate thesis is a molecular dynamics simulation of charged particles in a 2D harmonic trap, and that background is why I like to model a problem before writing the first line and to measure before I optimize.

## What I'm working on

- **RangoBox**, an ordering app to bring the sales of my own restaurant and store online
- Multi-tenant back ends with Fastify, Prisma and PostgreSQL
- Mobile apps with React Native and Expo
- System design: how real systems scale, fail and get split apart
- UI/UX, so what I build is also pleasant to use
- Finishing my Physics degree at IFCE and studying Computer Science at UniFanor Wyden
- On the side: machine learning and small language models
